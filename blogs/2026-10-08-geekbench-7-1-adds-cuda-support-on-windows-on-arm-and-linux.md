Geekbench 7.1 adds CUDA support for its GPU Benchmark on Windows on ARM and Linux, allowing NVIDIA GPU users on those platforms to run CUDA workloads. The release also updates TensorRT for RTX to version 1.6, expands it to both platforms, and adds a Vulkan cooperative matrix optimizer for compatible GPUs. CPU scores remain comparable with Geekbench 7.0, but GPU scores should only be compared with other Geekbench 7.1 results because of the CUDA and Vulkan changes.
