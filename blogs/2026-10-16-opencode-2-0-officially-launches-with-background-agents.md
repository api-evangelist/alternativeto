The open-source AI coding agent OpenCode has officially launched version 2.0 , about three months after its public beta began. The update introduces a shared local background service that connects its terminal, web, and desktop interfaces, alongside a rebuilt API and a new @opencode/client package that lets scripts automatically discover and interact with the service. The release also introduces Code Mode , allowing agents to write scripts that combine calls to MCP servers and OpenAPI endpoints within a single execution flow.
